Project Pad is a free, open-source Windows desktop launcher for organising and managing Unreal Engine projects, installed editors and locally downloaded assets. It runs as a standalone application without requiring Python or a separate browser.

Features include:
- Project scanning, recent projects and one-click launching.
- Multiple Unreal Engine installations and per-project engine selection.
- Coloured tags, search, sorting and project filters.
- Project health checks for descriptors, editor paths and declared plugins.
- Local Vault content management and non-overwriting imports into projects.
- Asset thumbnails with optional public Fab preview lookup and caching.
- Reusable project templates.
- Responsive card and list views, adjustable entry sizes and custom colour themes.
- Portable settings stored beside the application in its Saved folder.
Project Pad is independent of Epic Games and does not require an Epic account.
